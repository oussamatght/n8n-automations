# n8n Automations

This repository contains a step-by-step n8n automation learning path from beginner to advanced workflows.

## Structure

- 01-beginner: first automations using Google Sheets, Gmail, reminders, and data cleaning
- 02-intermediate: Telegram automation, weather notifications, and lead collection
- 03-ai: AI-powered email classification, task management, and customer support
- 04-advanced: RAG assistants and multi-agent orchestration
- 05-business: business automation workflows for AI-driven operations

## Getting started

1. Import the workflow JSON file into your n8n instance.
2. Configure the credentials and environment variables for each node.
3. Test the workflow in production mode only after validating the trigger data.
4. Keep the README alongside each workflow for setup guidelines.

## Notes

This repository is designed for learning, prototyping, and experimentation with n8n.
