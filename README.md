## ⚙️ Getting Started

### 1. Import a workflow

Import the corresponding `.json` workflow file into your n8n instance.

### 2. Configure credentials

Reconnect the required services and credentials such as:

- Google Sheets
- Gmail
- Telegram
- APIs
- Databases
- AI providers

### 3. Configure the workflow

Review:

- Trigger settings
- Expressions
- Environment variables
- API endpoints
- Input/output data

### 4. Test

Run the workflow manually first and verify every node before activating the automation.

### 5. Activate

Once everything works correctly, activate the workflow for automated execution.

---

## 🔐 Security

**Never commit secrets to GitHub.**

Do not publish:

- API keys
- Passwords
- OAuth secrets
- Access tokens
- `.env` files
- Private credentials
- Sensitive personal information

Use environment variables or n8n credentials instead.

For public portfolio projects, use **demo data and test accounts** whenever possible.
